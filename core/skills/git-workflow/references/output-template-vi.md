# Template trả lời tiếng Việt

Dùng các template này cho đầu ra git workflow hướng người dùng.

## Trước khi commit

```text
Branch đề xuất:
Commit đề xuất:
Lý do chọn type/scope:
Files sẽ stage:
Commit body:
Changed:
- ...
  • ...
- ...

Reason:
- ...
Important notes / Breaking impact:
- ...
Verification:
```

## Sau khi commit hoặc push

```text
Branch:
Commit:
Push:
PR:
Verification:
Ghi chú:
```

## Changelog hoặc release notes

```text
Phạm vi:
Đối tượng đọc:
Tóm tắt:
Changelog / Release notes:
```
